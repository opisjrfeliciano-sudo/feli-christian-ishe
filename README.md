# Project Descrition
- 1.1 Brief Explation of System Purpose
The Task-Manager System is primarily a system monitoring program used to provide information about the processes and applications running on a computer, as well as the general status of its hardware resources. Depending on the context, it can refer to a built-in operating system utility or a business tool for organizing work
- 1.2 Problem it solves:
A Task-Manager System, Process Management: It provides granular control, allowing users to adjust the priority of a process (e.g., setting a task to "High" or "Low" priority) or set CPU affinity to optimize performance.
